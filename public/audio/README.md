# 音效目录

把音效文件放在这个目录里。**全部可以不填** —— 没有文件时前台会安静地跳过播放，不会报错。

## 建议的文件清单

| 文件名 | 用途 | 建议时长 |
| --- | --- | --- |
| `rain-loop.mp3` | 雨声底噪，可循环 | 10–30 秒（无缝循环） |
| `rain-heavy.mp3` | 雨变大时的替换音轨 | 10–30 秒 |
| `vinyl-crackle.mp3` | 黑胶爆豆声 | 3–10 秒循环 |
| `click.mp3` | 点击咔哒（开灯、按按钮） | 0.1–0.3 秒 |
| `page-turn.mp3` | 翻日记的沙沙声 | 0.5–1 秒 |
| `letter-drop.mp3` | 树洞投信的「咚」 | 0.5–1 秒 |
| `cat-purr.mp3` | 猫呼噜 | 2–5 秒 |
| `radio-static.mp3` | 收音机沙沙声 | 3–10 秒循环 |
| `ui-hover.mp3` | 悬停物件时的极轻提示（可选） | 0.05–0.15 秒 |

## 规格建议

- 格式：`.mp3`（兼容性最好）优先，`.ogg` 作为备选；
- 单文件 **≤ 100 KB**，音效不需要高保真；
- 采样率 22.05 kHz、单声道足够；
- 用 `ffmpeg` 压一下：

```bash
ffmpeg -i 原始.wav -ac 1 -ar 22050 -b:a 96k click.mp3
```

## 两条硬规矩

1. **默认静音**：所有声音都必须等用户主动点一下才能播。
   浏览器会拦截自动播放，这是礼貌也是规定。
2. **可以完全关掉**：访客能在任何页面一键静音，关掉后不影响任何功能。
