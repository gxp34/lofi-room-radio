# 字体与素材

## 一、字体：默认为什么用系统字体

`src/app/globals.css` 里定义了两个字体的 CSS 变量：

```css
:root {
  --font-display: ui-monospace, SFMono-Regular, 'Space Mono', Menlo, Consolas,
    'Courier New', 'PingFang SC', 'Microsoft YaHei', monospace;
  --font-body: system-ui, -apple-system, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB',
    'Microsoft YaHei', 'Noto Sans SC', sans-serif;
}
```

Tailwind 里所有 `font-display` / `font-sans` 都指向这两个变量（见 `tailwind.config.ts`）。

这样做的好处：

- **离线也能 build**。`next/font/google` 会在构建时联网下载字体，
  在国内网络或被墙的环境下 `next build` 会直接失败。默认用系统字体，永远不会因为字体挂掉。
- **中文绝不缺字**。英文点阵字体（VT323 之类）根本没有汉字，直接用会满屏豆腐块。
- **首屏没有字体请求**，移动端更快。

代价是「标题的复古感」弱一些。想换成 Space Mono / VT323 / 霞鹜文楷，按下面任选一种。

## 二、方案 A：自托管字体（推荐，最稳）

1. 下载字体文件（`.woff2` 优先，体积最小）放进 `public/fonts/`：

```
public/fonts/
├─ SpaceMono-Regular.woff2
├─ SpaceMono-Bold.woff2
├─ LXGWWenKai-Regular.woff2     # 霞鹜文楷，中文字体，文件较大（几 MB）
└─ VT323-Regular.woff2
```

> 霞鹜文楷（LXGW WenKai）是 OFL 协议的开源字体，可以从
> <https://github.com/lxgw/LxgwWenKai/releases> 下载。
> 中文字体动辄 5–15 MB，**建议先用 `fonttools` 做子集化**，或者只用来渲染标题的少量字。

2. 在 `globals.css` 顶部加 `@font-face`：

```css
@font-face {
  font-family: 'Space Mono Local';
  src: url('/fonts/SpaceMono-Regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;   /* 先把文字用系统字体显示出来，字体到了再换，避免白屏 */
}
@font-face {
  font-family: 'LXGW WenKai Local';
  src: url('/fonts/LXGWWenKai-Regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
```

3. 改 `:root` 里的变量：

```css
:root {
  --font-display: 'Space Mono Local', ui-monospace, Menlo, monospace;
  --font-body: 'LXGW WenKai Local', system-ui, 'PingFang SC', sans-serif;
}
```

完成。全站字体立刻生效，Tailwind 不用动。

## 三、方案 B：next/font/local（有类型提示，构建期做子集）

```ts
// src/app/fonts.ts
import localFont from 'next/font/local'

export const fontDisplay = localFont({
  src: [
    { path: '../../public/fonts/SpaceMono-Regular.woff2', weight: '400', style: 'normal' },
    { path: '../../public/fonts/SpaceMono-Bold.woff2', weight: '700', style: 'normal' },
  ],
  variable: '--font-display',
  display: 'swap',
  fallback: ['ui-monospace', 'Menlo', 'monospace'],
})
```

然后在 `src/app/layout.tsx` 里：

```tsx
import { fontDisplay } from './fonts'

<html lang="zh-CN" className={fontDisplay.variable}>
```

因为变量名相同（`--font-display`），Tailwind 那边一行都不用改。

## 四、方案 C：next/font/google（最简单，但构建要联网）

```ts
// src/app/fonts.ts
import { Space_Mono, VT323 } from 'next/font/google'

export const fontDisplay = Space_Mono({
  weight: ['400', '700'],
  subsets: ['latin'],
  variable: '--font-display',
  display: 'swap',
})
```

⚠️ 三个坑：

1. **构建时必须能访问 `fonts.googleapis.com`**，否则 `next build` 失败。
2. Google Fonts 上的中文字体是**分片（unicode-range）**加载的，
   霞鹜文楷在 Google Fonts 上的名字是 `LXGW_WenKai_TC`（繁体优先），简体请用自托管。
3. Vercel 构建机在境外，能联网；但你本地可能不行，所以本地开发会报错。

## 五、音效与背景音

`public/audio/` 目录用于放**音效**（雨声、黑胶爆豆、点击咔哒、翻页沙沙、投信咚）。
这些是短音频，建议：

- 格式：`.mp3`（兼容性最好）或 `.ogg`（体积更小），单文件控制在 100 KB 以内；
- 采样率：22.05 kHz 单声道就够了，音效不需要高保真；
- 命名：语义化，全小写加连字符，例如 `rain-loop.mp3`、`click.mp3`、`vinyl-crackle.mp3`。

`public/audio/README.md` 里列了完整的文件名清单。

> **两条硬规矩**（写在这里防止以后忘）：
> 1. 所有音频**默认静音**，必须等用户点一下才能播（浏览器的自动播放策略，也是礼貌）；
> 2. 音效必须能单独关掉，且关掉后不影响任何功能。

## 六、图片素材

- 房间背景、家具插画建议用 **SVG**（可缩放、体积小、能跟着色板换色）；
- 照片类素材用 `.webp`，单张控制在 200 KB 以内；
- 放在 `public/` 下的图片走 `next/image` 时无需额外配置；
  放在 Supabase Storage 的图片已经在 `next.config.mjs` 的 `remotePatterns` 白名单里。
